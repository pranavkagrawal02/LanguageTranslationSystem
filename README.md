# Language Translation System (English → Hindi)

## Overview
This project implements an English-to-Hindi translation system using pretrained transformer-based NLP models.

## Models Used
- MarianMT (Helsinki-NLP)
- mBART
- IndicTrans

## Features
- No training required (inference-only)
- Multiple model comparison
- Jupyter Notebook-based implementation
